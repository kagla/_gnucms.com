# NHN KCP REST API 공개 테스트 인증 정보

- `splCert.pem`: [KCP 테스트용 서비스 인증서](https://developer.kcp.co.kr/download/cert/splCert.pem)
- `splPrikeyPKCS8.pem`: [KCP 테스트용 암호화 개인키](https://developer.kcp.co.kr/download/cert/splPrikeyPKCS8.pem)
- `settings.php`: 사이트 코드 `T0000`과 KCP [REST API 전환 가이드](https://developer.kcp.co.kr/guide/rest-api-guide)에 나오는 공개 테스트 개인키 비밀번호 `changeit`

이 파일들은 KCP 개발자센터가 공개한 테스트 자료다. 운영 상점 인증 정보로 사용하지 않는다.
