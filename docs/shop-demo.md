# 쇼핑몰 데모

이 저장소의 쇼핑몰 데모는 `scripts/seed_shop_demo.php`로 만든다. MySQL/MariaDB로 설치된
개발·스테이징 사이트에서 `php scripts/seed_shop_demo.php`를 실행하면 10개 분류, 30개
예시 상품과 이미지를 등록하고 이니시스 **테스트** 신용카드 결제 환경을 선택한다.
같은 상품 코드가 있으면 건너뛰므로 다시 실행해도 상품이 중복되지 않는다.

램프·머그 세트·스니커즈·헤드폰·피자 키트 5개 상품에는 선택옵션과 추가옵션이
함께 등록된다. 데모 시드를 다시 실행하면 이 5개 상품의 옵션 구성과 재고를
`shop-demo-catalog.json`에 기록된 값으로 맞춘다.

도서 3개와 국내산 다육식물 1개는 면세 상품으로 등록한다. 전체 30개 중 4개로
약 13.3%이며, 상품 상세와 주문 화면에서 과세 여부를 확인할 수 있도록 세금 표시를
켠다. 데모 시드를 다시 실행하면 상품명과 면세 상태도 카탈로그 값으로 맞춘다.

상품과 이미지 출처는 [상품 목록](shop-demo-catalog.json)에 함께 기록했다. 이미지는
Openverse에서 찾은 CC0 자료를 원본 제공처에서 내려받아 정사각형 JPEG로 변환한다.
저장 위치는 `storage/demo-images/final/`과 `storage/uploads/youngcart/`이며, 둘 다
런타임 데이터다. 데모를 다른 서버로 옮길 때에는 DB와 업로드 파일을 함께 옮긴다.
사진은 실제 판매 상품의 확인 자료가 아니라 기능 체험용 예시다.

스크립트는 `shop-demo@example.test` 회원을 처음 한 번 만들고 비밀번호를
`storage/shop-demo-member.json`에 저장한다. 이 파일은 저장소에 포함하지 않는다.
기존 회원의 비밀번호는 재실행해도 바꾸지 않는다.

이니시스 설정은 공개 테스트 MID `INIpayTest`와 공개 테스트 키를 암호화해 DB에
저장한다. 주문서에는 테스트 카드 수단만 표시하며, 실제 승인 확인에는 브라우저
결제창과 이니시스 콜백 검증이 필요하다. 운영 결제 전환에는 별도로 발급받은
상점 MID와 인증 정보를 관리자 설정에 입력해야 한다.
