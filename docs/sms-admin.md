# 자동 문자와 관리자 편집

관리자 설정 → 알림별 발송 규칙(`/admin/settings/notifications`)에서 이벤트별 SMS·알림톡·이메일을 선택한다. 사이트 내 알림은 항상 기록하며 사용자가 끌 수 없다. 이메일 기본 수신·수신거부는 기존 정책을 유지한다. 문자·알림톡에는 회원 수신거부 설정이 없다.

## 자동 발송 지점

사이트 전체 채널 사용은 **설정 → 알림·발송**(`/admin/settings/messaging`)의 네 항목에서 관리한다. 사이트 내 알림은 필수 표시이며, 메일은 사용 안 함·자체 서버·SMTP 선택 후 저장한다. SMTP 선택 시에만 서버·계정 입력란을 펼친다. 카카오 알림톡과 문자는 OFF·ON 토글로 즉시 저장한다. 둘 다 ON이면 알림톡 실패 시 문자 대체, 알림톡만 ON이면 문자 대체 없음, 문자만 ON이면 문자만 사용한다. 현재 조합 안내는 저장 응답과 실패 후 실제 상태 재조회 결과에 맞춰 갱신한다. 알리고 계정 연결과 알림별 발송 규칙·문구 편집은 상세 화면 링크로 연결한다. 채널 끄기의 예약 취소·부분 취소 안내와 기존 메일 비밀번호 보존을 유지한다. 배포는 현재 채널 선택을 변경하지 않는다.

| 기능 | 발생 시점 | 중복 처리 |
| --- | --- | --- |
| 가입·비밀번호 재설정·변경 | 기존 회원 서비스의 해당 이벤트 | 기존 토큰·계정 흐름 유지 |
| 댓글·답글 | 댓글 저장 | 자기 자신 제외, 글·부모댓글 작성자 중복 제외 |
| 주문 접수 | 새 주문 INSERT 성공 | 같은 주문서 키 재요청 제외 |
| 결제 완료 | PG 승인 또는 입금 확인 최초 저장 | 동일 결제 재통보 제외 |
| 상품 준비·배송 중·배송 완료·취소 | 상태 전이 성공 | 실패한 전이·동일 상태 제외. 상태 되돌리기는 발송하지 않음 |
| 환불 | 새 환불 원장 기록 | 같은 환불 키 재요청 제외, 부분 환불마다 해당 건 금액 사용 |
| 상품문의 답변 | 첫 답변 등록·내용 변경 | 동일 본문 저장·빈 답변 삭제 제외 |

필수 알림은 업무 데이터와 같은 거래에 기록한다. 외부 발송은 최외곽 거래가 커밋된 뒤에 시작한다. CSV 및 결제 내부 거래에서도 롤백되면 발송 콜백이 제거된다. 발송 실패가 성공한 업무 저장을 취소하지 않는다. 기존 요청당 외부 호출 시간 제한과 접수 결과 불명 재시도 방지 정책을 유지한다. 주문 접수 후 즉시 결제되는 주문은 서로 다른 두 이벤트이며, 관리자가 둘 다 켜면 두 안내가 발생한다. 환불 후 주문 취소도 별개 이벤트다.

수신자는 활성 회원의 계정 연락처다. 배송지 수령인에게 안내하지 않는다. 번호가 없으면 전화 채널은 건너뛴다. 상품문의 알림에는 비공개 문의·답변 내용을 담지 않는다. 문자 링크와 알림함은 문의 소유권 확인 후 상품의 해당 문의 페이지로 안내한다.

## 이메일 편집과 수신 미리보기

모든 코어 알림의 편집 창에 이메일 제목·본문 입력란을 제공한다. 기존 `MailBodies`의 문구를 기본으로 표시하며, 전화 채널을 지원하지 않는 알림 카드에는 기본 또는 저장된 이메일 제목·본문을 직접 보여 준다. 전화 지원 카드에는 문자 문구와 이메일 제목을 함께 표시한다.

- 제목은 최대 200자, 본문은 최대 20,000자의 일반 텍스트다. 이벤트가 제공하는 `#{변수}`만 사용할 수 있으며 제목 또는 본문의 마지막 선택 위치에 변수 버튼으로 삽입한다. 알 수 없는 변수·잘못된 마커·빈 제목/본문·제목 줄바꿈·제어 문자는 서버에서 거절한다.
- 기본 이메일 문구 넣기와 저장된 이메일 문구로 되돌리기를 제공한다. 복원 버튼은 편집란만 바꾸며, 알림별 저장 버튼을 눌러야 적용된다. 기본값으로 저장하면 별도 고정 사본 대신 코어 기본 문구를 사용한다.
- 이메일 수신 내용 미리보기는 관리자 권한·CSRF를 확인한 POST에서 현재 입력 문구에 예시 값을 넣어 제목·본문을 보여 준다. 실제 발송과 같은 치환 경로를 쓰고, 미리보기 성공 후 결과 위치로 이동한다. 설정 저장·SMTP 호출·실제 메일 발송·실제 인증/수신거부 토큰 발급은 하지 않는다. 메일 앱별 글꼴·링크 표시는 달라질 수 있다.
- 구독 알림의 미리보기에도 예시 수신거부 링크와 재수신 안내를 붙인다. 실제 발송의 서명된 수신거부 링크는 기존 `MailPreferences`가 본문 뒤에 자동 추가하며 관리자 문구 편집으로 제거할 수 없다. 직접 요청한 인증·계정 복구 메일에는 수신거부 안내를 붙이지 않는다.
- 비밀번호 재설정·이메일 인증·소셜 이메일 확인 본문에는 `#{링크}`와 `#{유효시간}`을 유지해야 한다. 미리보기에도 두 예시 값이 필요하다.
- 기존 `site_settings`에 `notify.<event>.mail_subject`와 `notify.<event>.mail_body`를 저장한다. 채널이 꺼져 있어도 문구를 보존하고 편집할 수 있다. 문구를 보내지 않은 기존 저장 요청은 이전 값을 보존한다. DB 구조·스키마 51·제품 버전은 변경하지 않는다. 이메일 전역 설정·이벤트별 선택·기본 수신/수신거부 정책은 그대로 적용한다.

## 문자 편집 화면

- 알림 목록은 입력 박스 크기의 문자 문구를 항상 보여 주는 카드 그리드다. 하단에는 사용·미사용·필수 채널 설정과 전역 꺼짐·연결 확인 배지를 표시한다. 문구 영역은 스크롤·선택·복사할 수 있으며 편집을 누르면 상세 설정을 연다.
- 알림 검색, 문자 가능한 이벤트 필터, 발송 시점·수신 대상 설명과 이벤트별 이력 링크.
- `회원`으로 가입 완료·가입 시도·이메일 인증·소셜 로그인 이메일 확인·비밀번호 재설정·비밀번호 변경 알림을 함께 찾는다. `비밀번호 찾기`, `비번 찾기` 같은 표현도 지원하며, 띄어쓰기 없이 입력하거나 `회원 비밀번호 찾기`처럼 여러 검색어를 조합할 수 있다. 제목·문자 문구·채널 배지 검색과 문자 가능 필터는 함께 적용한다.
- 고정 LMS 제목(선택, EUC-KR 44바이트), 문자 본문(2,000바이트), 이벤트별 기본 문구와 저장 문구 복원.
- 변수 버튼은 커서 위치에 삽입한다. 배송 이벤트는 택배사·운송장번호·배송정보 변수를 추가 제공한다. 배송정보가 비어 있으면 주문 조회에서 확인하도록 치환한다.
- 편집 중 바이트 수는 추정값이다. 미리보기 버튼은 관리자 권한과 CSRF를 확인하고 서버의 `MessageText`로 예시 치환·인코딩·정확한 바이트·SMS/LMS 분류를 검증한다. 알리고 호출·설정 저장·과금은 하지 않는다. 예시 값은 저장하지 않으며 편집하면 지난 미리보기를 숨긴다.
- 실제 발송에서는 `Dispatch`가 수신자별 치환 후 다시 검사하고 90바이트를 넘으면 LMS로 분류한다. 이모지 등 EUC-KR에 없는 문자는 거절한다. 제목에는 변수를 허용하지 않는다.
- 문자·알림톡을 함께 켜면 기존 알림톡 우선·실패 시 문자 대체 정책을 따른다. 전역 SMS 설정과 해당 이벤트 설정을 모두 켜야 자동 문자가 나간다. 신규 이벤트의 외부 채널은 관리자 선택 전까지 꺼져 있다.

## 직접 보내기

회원 수정·주문 상세·상품문의 관리에서 수신 회원을 선택한 발송 화면을 연다. 주문·문의에서는 해당 업무 값도 가져온다. 알림 편집 화면에서는 저장 문구를 가져올 수 있다. 예시 값이나 일회용 비밀은 자동으로 채우지 않는다. 이 화면은 미리보기·직접 발송·예약·중복 제출 방지·결과 이력을 제공하는 기존 AligoService 경로를 사용한다. 화면을 여는 것만으로 발송되지 않으며 관리자가 발송 버튼을 눌러야 접수된다. 직접 발송은 이벤트 자동 선택과 별개인 관리자의 명시적 발송이며 전역 채널 스위치를 따른다.

## 스키마 51

`notifications.feedback_id BIGINT NULL`을 신규 설치 DDL과 멱등 마이그레이션에 추가한다. 기존 알림과 이메일 기본 수신 설정은 변경하지 않는다. `version.txt` 제품판은 별도로 유지한다.
