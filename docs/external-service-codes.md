# 외부 서비스 코드

설정 → 기본·홈 → 외부 서비스 코드에서 사이트 소유 확인 태그, 애널리틱스 코드,
애드센스 코드를 각각 저장한다. 저장한 코드는 기본 테마의 공개 화면 `<head>`에 출력하며,
관리자 화면에서는 실행하지 않는다. 신뢰하는 서비스에서 발급한 코드만 사용한다.

GNUCMS는 광고·분석용 동의 관리, CMP 연동, 동의 상태에 따른 코드 차단과
하단 개인정보·쿠키 설정 버튼을 제공하지 않는다. 동의 관리가 필요한 사이트는 운영자가
외부 서비스와 테마에서 별도로 구성한다. 애드센스 계정에 게시한 메시지는 해당 계정에서 관리한다.
회원가입 약관과 개인정보 문서의 동의 및 동의 기록은 별도 기능으로 유지한다.

## 기존 설치 업그레이드

기존 애널리틱스·애드센스 코드와 사이트 소유 확인 태그는 보존한다. 예전 광고·분석
동의 관리 설정은 기본 테마의 코드 출력에 사용하지 않는다. DB 구조 변경이나 설정값 삭제는 없다.
기존에 동의 관리로 차단하던 코드도 공개 화면에서 실행되므로, 외부 동의 연동이 필요한
사이트는 업그레이드 전에 그 구성을 준비한다. 예전 CMP 연동 코드 칸에 저장한 코드는
자동으로 실행하거나 애널리틱스·애드센스 칸으로 옮기지 않는다.

독립 테마는 `layout.php`의 `external_service_head` 블록을 기본 테마와 같이 갱신하고
`_privacy_head`·`_privacy_links` 삽입과 `privacy.js` 연결을 제거한다.
관리자 레이아웃의 빈 `external_service_head` 블록은 유지한다.
